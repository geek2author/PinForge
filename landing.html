核心功能模块

🔧

多芯片支持

不绑定特定芯片：导入 CSV/XLSX 引脚数据或从零创建，内置 ESP32-P4、STM32G474 示例一键加载。

🎯

可视化配置

QFP/QFN、DIP、BGA 多封装图形布局，组模式/单信号精细映射，支持平移缩放与触摸手势。

⚠️

冲突检测

基于引脚复用表实时校验分配合法性，冲突信号高亮告警，提前发现配置问题。

🪄

自动排布与外设快加

自动识别 UART/SPI/I2C/USB 等外设实例，点击一次整组接入；也可按约束强度一键把全部未分配信号自动排布到空闲引脚。

🛡️

设计审查 DRC

除冲突检测外，实时检查调试口占用、差分对完整性、IO 利用率等工程规则，发现项一键定位到信号。

💧

电源域分析

按供电轨（VDD_LP / VDD_IO_x / VDD_FLASHIO…）给引脚着色，图例显示每轨分配进度，可隔离查看单一电源域。

📄

代码生成

一键生成 C 头文件（#define 引脚宏 + 配置表）、ESP-IDF / STM32 HAL GPIO 初始化代码与 Markdown 配置报告。

🔗

链接分享

整个配置压缩进 URL（无需服务器），复制链接发给同事，打开即恢复完整配置方案。

💾

自动保存

工作会话自动保存到本地，刷新不丢失；撤销/重做（Ctrl+Z / Ctrl+Y）随时回退，亮暗主题随心切换。

安装与使用指南

1

克隆项目

从 GitHub 克隆项目到本地

git clone https://github.com/geek2author/PinForge.git
2

安装依赖

进入项目目录并安装依赖

cd PinForge
npm install
3

启动开发服务器

运行开发命令启动本地服务器

npm run dev
4

构建部署

构建生产版本并部署

npm run deploy

常见问题解答

无需写代码：直接导入该芯片的引脚数据 CSV/XLSX（第一列序号、第二列管脚名、第三列类型、后续列为复用功能），即可自动生成信号列表与芯片图。也可以在欢迎页"从零创建芯片"，逐脚填写复用功能后导出 CSV 作为引脚数据表。

冲突通常发生在信号被分配到不支持它的引脚，或同一信号被分配到多个引脚时。例如把 UART0_TX 分配到一个复用表中没有该信号的 GPIO。系统会实时检测并在信号列表与引脚上标红提示。

目前支持导出：C 头文件（#define 引脚宏 + 配置汇总表，适用于 ESP-IDF / STM32 HAL 等框架）、Markdown 配置报告、配置 JSON、引脚表 CSV / XLSX。后续版本将支持更多格式。

不会。工具会把当前工作会话自动保存到浏览器本地存储，刷新或关闭页面后重新打开即可恢复。重要节点建议再导出一份配置 JSON 存档，误操作也可用 Ctrl+Z 撤销。
